# Samri & Oli — QR Gift Website

This folder contains the complete static website for the QR gift.

## Files
- `index.html` — the story
- `style.css` — design and animations
- `script.js` — smooth scrolling and reveal effects
- `images/` — the three uploaded photos

## How the QR code works
The QR code should point to the public URL of this website after you publish it.

Easy free options:
1. GitHub Pages
2. Netlify
3. Vercel

After publishing, send me the final website URL. I can then create a final QR code that points directly to it and a matching printable gift-card design.
